# Skills section and its panel

Read before changing the skills data, its bars or the skill panel. Moved from CLAUDE.md unchanged.

- **Skills**: `coreTechStack` and `courses` in `src/data/home.js`. A skill's bar is its share of everything it can be used in: each project, each experience entry with `tags`, and each course (`{ code, tags }`), shaded `█` project `▓` job `▒` course in one 16-cell bar (`src/lib/skills.js`: cells = `round(share × 16)`, each used source keeps at least one, the rest by largest remainder). A tag matches a skill exactly or as a prefix word ("Tailwind" ↔ "Tailwind CSS"); `via` lists tags that count as the skill and show beside the item in its "used in" line (Oracle Database for SQL); `all` is a skill every item uses (Git). An experience entry with a `project` slug is the same work as that project, so the pair is one item (a job, named "job / project"): nothing counts twice. A skill nothing uses fails `test/data.test.mjs`.
- **Skill panel** (`components/skills/Skills.jsx`): hovering, selecting (j/k, or Tab: the list is one roving Tab stop, the selected row) or tapping a skill row opens a `tree`-style "used in" panel (`uses` from `buildSkills`): the projects as buttons (a job merged with its project among them, company muted), then the jobs and courses in one muted line. It renders only while open (App's `skillOpen` = `{ name }`, so Esc closes it through the key router's `closeSkill`, ahead of every other Esc), floats over the page (no height changes) and flips above the row when the bars would cover it. A project button calls App's `jumpToProject`: the filter goes back to `all` if it hides the project, then `goSec(1, row)` selects the row without opening it. Pinned by `skills panel…` in the browser check. Keys: j/k select a skill and its panel shows (display only); **Enter/Space** go into the panel (`enterSkillPanel`), where j/k, ↑/↓ and ←/→ walk its buttons (`panelStep`, wraps; Home/End), Enter jumps, **Esc** hides the panel and returns to the row (selection stays), Tab leaves (no trap). The panel measures itself (`fit` in `Skills.jsx`) and flips above the row when the bars would cover it.
